🍽️ Epicurean Enthusiasts – Restaurant Menu 

Simple, Interactive, and User-Friendly Food Ordering Experience

Epicurean Enthusiasts is a modern web-based restaurant menu  that allows users to explore meals, filter by categories, and add items to a cart with real-time total price calculation.

🚀 Live Demo

👉 https://yarabakr.github.io/EpicureanEnthusiasts/

✨ Project Overview

This project focuses on building an interactive restaurant menu where users can:

Browse food items
Filter meals by category
Add items to cart
View total price dynamically
Navigate through multiple pages

The goal is to simulate a real-world food ordering experience with a clean UI and smooth interactions.
